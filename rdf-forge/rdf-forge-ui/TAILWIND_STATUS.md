# Tailwind Status — Dead Config

**Audit flag:** 2026-04-21 (P3)

## Situation

`tailwind.config.js` exists at the repo root but Tailwind is **not integrated**:

- No `@tailwind base;` / `@tailwind components;` / `@tailwind utilities;` directives in
  `src/styles.scss`.
- `tailwindcss` is NOT currently listed as a dependency in `package.json` (confirmed 2026-04-21).
- The app relies on Angular Material + Oblique + custom SCSS in `src/styles.scss`. Utility
  classes like `.text-sm`, `.gap-2`, `.flex-center` are hand-rolled in `styles.scss`, not
  generated by Tailwind.

## Decision Needed

Pick one of two paths (future maintainer):

### Option A — Integrate Tailwind
1. Add `tailwindcss`, `postcss`, `autoprefixer` to `devDependencies`.
2. Add `@tailwind base; @tailwind components; @tailwind utilities;` at the top of
   `src/styles.scss`.
3. Verify Angular 21 PostCSS pipeline picks it up (may need `postcss.config.js`).
4. Remove the hand-rolled utility classes in `styles.scss` that duplicate Tailwind.

### Option B — Remove Tailwind config (recommended)
1. Delete `tailwind.config.js`.
2. Delete this `TAILWIND_STATUS.md`.
3. Keep current hand-rolled utility classes in `styles.scss`.

## Why "Option B recommended"

- Angular Material + Oblique already covers most styling needs.
- Hand-rolled utility classes in `styles.scss` are already in use throughout templates.
- Adding Tailwind now would either introduce duplicate styling systems or require a
  full migration of existing `.text-sm` / `.gap-2` / etc. usages.

## Action Taken in This Audit

- TODO comment added to `tailwind.config.js`.
- This status file created for future maintainer context.
- **No removal** performed — deferred to deliberate decision.
